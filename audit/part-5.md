# Audit part 5: old SJIBL videos 16 to 24 (18 videos, 108 frames)

Slice: `16-bms-insurance-management-*` through `24-invoicing-payment-module-accounting-side-*`, admin and user
for each. All 108 sampled frames were read. Old frames come from
`scratchpad/oldaudit/<video>/f??_t<secs>s.jpg` (sampled every ~3 to 5 s). Frame names below are
`f<index>_t<seconds>`.

Live verification was done on the deployed build (web 10.2.1.50:8080, api :8081, tenant `shatadal`,
build `e86285b27` web / `714cea339` api) with dev-auth headers. Personas were built from the REAL
permissions of each role in `design-contract/ui/role-catalogue.json` (fleet-manager 31, employee 234,
store-keeper 113, security-officer 65, insurance-officer 13, security-administrator 52). The old
"admin" videos were a demo admin holding every role, so those screens were checked with a broad
pack-bundle persona (`<pack>.*` for all 55 packs), called `admin-all` below. Full-page screenshots
were taken for every route and read; text patterns alone are not trusted (the first pass missed that
the Vehicle list error had merely been reworded).

## Summary

- 4 high-severity list or panel failures from the old videos STILL fail live (Vehicle list, Canteen
  menu day list, Canteen order list, Order lunch "My recent orders"). All four are one bug class:
  a list or block that hops through or selects a column the spec does not declare as a reference or
  a visible column. The raw `query_not_a_reference` / `query_template_column` wording has been
  softened since 2026-09-18, but the screens still show an error and a "Try again" button instead
  of data.
- 1 high failure is FIXED-SINCE: the Issue list (`inv.issue.to_org_unit_id`) now loads.
- The rest is mostly systemic developer commentary and raw names shown to end users (form hints,
  search-box labels, a report key where a KPI number belongs, "not resolved", stale hard-coded
  breadcrumbs). All still present live.
- The tenant-administrator role as catalogued cannot open the canteen, Party, Committee, fleet or
  inventory screens at all (live: "You do not have permission for this. Ask a tenant administrator
  to grant this permission."). The old admin videos only worked because that login held every role.
  Confirm this is intended before the bank logs in as `tenant-administrator`.
- Module 24 is the separate accounting app: its findings are audited from frames only.

Counts (issue rows below): 27 issues.
By live status: STILL-REPRODUCES 19, FIXED-SINCE 3, NOT-CHECKABLE 5.
By severity: high 5 (4 still reproducing, 1 fixed), medium 16, low 6.
