# Audit of old SJIBL videos, slice 1 of 5

Slice: 11 videos, 124 frames read (module videos frame by frame, officer-full videos via 2x2 contact sheets).
Old videos were recorded 2026-09-18 on the old kind cluster. Live checks ran on 2026-09-21 against the
deployed build (web `e86285b27`, api `0d3d5accc`, tenant `shatadal`), using dev-auth headers built from the
REAL permissions of each role in `design-contract/ui/role-catalogue.json` (not `proc.*`).

Note on the live environment: every live screenshot carries the red banner "This deployment is running with
development authentication. You are not signed in." That is the dev-auth cluster itself, not a product defect,
and is not counted below. The old Casdoor sign-in frames (00a, 00b) cannot be reproduced live for the same reason.

- 24 issues logged. Live status: 18 STILL-REPRODUCES, 2 FIXED-SINCE (5, 10), 1 mixed (22: access fixed, denied-page heading still raw), 3 NOT-CHECKABLE (6, 8, 9). Issues 12 and 18 are confirmed by the same pattern on other live screens rather than by re-opening that exact screen.
